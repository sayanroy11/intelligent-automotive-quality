# Brake Sensor Troubleshooting Guide

## Signal Error
Possible causes:
- Damaged wiring
- Connector problem
- Sensor communication failure

Recommended actions:
- Inspect sensor wiring
- Check electrical connectors
- Test sensor communication

## Calibration Error
Recommended actions:
- Recalibrate the sensor
- Verify sensor alignment
- Repeat the diagnostic test

## No Signal
Recommended actions:
- Inspect power supply
- Check wiring continuity
- Replace the sensor if required
