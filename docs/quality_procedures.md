# Automotive Quality Investigation Procedure

## Investigation Process

When a quality issue is reported:

1. Identify the affected component.
2. Determine the supplier.
3. Review historical inspection records.
4. Identify recurring fault patterns.
5. Check fault severity.
6. Review the relevant troubleshooting documentation.
7. Determine the recommended corrective action.
8. Document the investigation result.

## Supplier Quality

If one supplier shows a significantly higher fault rate than others:

- Compare the number of inspections between suppliers.
- Calculate the fault rate instead of using only raw fault counts.
- Check whether the issue is limited to a particular component type.
- Review repeated fault patterns.
- Escalate persistent quality issues for supplier investigation.
